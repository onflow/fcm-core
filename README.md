## Installation

### Prerequisites
- [Foundry](https://book.getfoundry.sh/) (`forge`, `cast`, `anvil`, `chisel`)
- `git` (for submodule-based dependencies)
- `make`

### Install Foundry
```sh
curl -L https://foundry.paradigm.xyz | bash
source ~/.zshenv   # or restart your shell
foundryup
```
